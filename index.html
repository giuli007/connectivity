    What this measures

    Each check requests a small file from this site, not the whole internet. A failed request can also mean the site is unavailable. The first failed and next successful checks only bound an outage; durations use the midpoint of those bounds. When the browser is closed, asleep, or substantially delayed, that period is marked unobserved instead of counted as downtime.
